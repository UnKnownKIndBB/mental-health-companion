🧠 Mental Health Companion Chatbot
Overview

AI-powered emotional support chatbot for Indian college students facing stress, anxiety, and loneliness.

⚠️ Not a replacement for therapy.

Features
1.Mood Detection (Transformers + VADER)
2.Empathetic Responses
3.Crisis Escalation (AASRA: 9820466726, US: 988)
4.Relaxation Techniques
5.Student-focused motivation

Tech Stack
  Python
  Streamlit
  HuggingFace Transformers
   VADER Sentiment

 
 
 pip install -r requirements.txt
streamlit run app.py
